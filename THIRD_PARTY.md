# Third-Party Components

No third-party runtime code, fonts, icons, datasets, assets, or adapted code are distributed. Runtime packages are Flask and python-dotenv, declared with bounded versions in `pyproject.toml` and `requirements.txt`.

Development tooling is declared in `pyproject.toml`; its exact resolved versions and licenses are not recorded here because no lockfile or installed release artifact is committed. Before shipping a release, record each included component's name, version, purpose, license, authoritative source, and attribution requirements here.
